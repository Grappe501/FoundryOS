## Grammar

| Token | Meaning |
|---|---|
| `depth` | How far the room has disclosed (`void` → `equipped`) |
| `machine` | `dormant` / `aware` / `equipped` — systems underneath |
| `origin` | `found` vs `made` |
| `place` | `pulse` / `draft` / `made` — where the object sits |
| `object-state` | `found` → `touched` → `opened` → `changed` → `persisted` |
| `presence` | `absent` / `ghost` / `focus` |
| `material` | Bench plate, not a card |

Motion only answers: what physically or systemically changed?

## What 2.0 added

- Off-axis far structure. Left rail. Deep rail that wakes when equipped.
- Bench as a spatial plate. MAKE moves the participant closer. The room reconfigures; it does not brighten.
- Jobs are scraps with a struck assumption and a time mark. Not cards.
- Writing happens inside the object (`data-object-state="opened"`).
- Their artifact is `origin=made`. Equipped draws a faint connection toward the deep rail.
- Mobile is a narrower window into the same room. Objects may leave the viewport.
