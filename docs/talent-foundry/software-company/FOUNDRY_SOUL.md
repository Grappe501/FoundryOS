# Foundry Soul Engine

**Status:** 1.0 — architecture live under Company Foundry. Not a chatbot.  
**Code:** `apps/platform/lib/talent-foundry/implementations/company/soul/`  
**Held:** Remember Me, GitHub, Cursor, Oscar, cohort exposure, production.

We are not designing an interface with personality. We are designing **a place capable of forming a history with someone.**

---

## Relationship

```txt
This place knows what I have done here.
```

Not:

```txt
This AI knows who I am.
```

Memory is shared history. Never inferred personality. Never surveillance. Never “we analyzed you.”

---

## Personality

Observant. Restrained. Curious. Consequential. Slightly mischievous. Demanding. Generous. Alive.

It notices meaningful work. It does not clap. Sometimes **silence is the response.**

---

## Loop

```txt
Curiosity → Agency → Friction → Discovery → Attempt → Competence → Consequence → Recognition → Increased Capability → New Mystery
```

Stronger than task → points → badge. The reward is environmental change and increased agency.

The Capability Reveal Engine still stands. This loop is the psychology underneath it.

---

## Variable discovery, not variable rewards

The uncertainty is **what will I discover?**, not **will the machine give me my reward?**

A mark wakes. A rail becomes legible. Work they left is still there. A two-line observation appears and waits. No slot machine. No streak.

---

## What the engine governs

| Layer | Job |
|---|---|
| Memory | Truthful place-facts from evidence |
| Presence | How alive the room feels |
| Consequence | How actions altered the Workshop |
| Recognition | Rare acknowledgment. Never praise. |
| Mystery | What remains unexplained |
| Trust | What becomes reachable after demonstrated work |
| Relationship | Continuity with artifacts and the place |
| Rhythm | Silence, friction, tension, resolution |
| Voice | The very small amount of language |

Ernie, Burt, and later Oscar inhabit this architecture. They are not the architecture.

---

## Ethical rule

FoundryOS optimizes for **capability and voluntary return — not time-on-platform.**

Never punish leaving. Never manufacture urgency, streak loss, social rejection, or fake human messages. Never withhold a necessary fact to increase engagement. Never infer psychological vulnerability.

They should want to return because they have unfinished work here, something they made matters here, people they respect are here, or they become better here.
