# Company Foundry — Phase 1.2 Experience Polish

**Status:** **APPROVED** (Ernie 2026-09-02). PR comment [5505686270](https://github.com/Grappe501/FoundryOS/pull/5#issuecomment-5505686270).  
**Parent:** Phase 1.1 HOLD was productive. Phase 2 / MAKE is now **cleared**.

---

## Governing principle

> **Nothing should look “designed to impress.” It should look like the system has a reason to exist without the visitor.**

Linger is the metric. Leaving should feel slightly premature.

---

## What this pass changed (UI only)

- Longer silence on the door. The threshold mark arrives before the word Enter.
- Named uses the same type as the room. Not a brand slide.
- Pulse and the draft sit without card chrome. They were already here.
- Fields do not resize like a form. Choices are notes, not a settings list.
- Linger: objects stay more present than the voice. “You can go.” is small. The bench line waits longer. Start over is later and almost gone.
- Light at named/linger is quieter than a reveal. The room does not brighten to congratulate.
